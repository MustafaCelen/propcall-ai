Adım 1 — Vapi API Anahtarı

Vapi hesabınız yoksa buradan ücretsiz açın (10$ hediye kredi ile başlarsınız). Sonra Dashboard → API Keys sayfasından bir private key oluşturup buraya yapıştırın.

🔒 Anahtarınız AES-256 ile şifrelenip veritabanında saklanır. Kimse okuyamaz.

Adım 2 — Telefon Numarası

Aramaları hangi Vapi telefon numarasından yapmak istiyorsunuz?

Numara yoksa Vapi Dashboard → Phone Numbers'tan Twilio numara alıp ekleyin, sonra tekrar başlatın.

Aramalarda kullanılacak Vapi asistanı.
